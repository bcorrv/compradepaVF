# Compra Depa VF

Plataforma pública y modular para evaluar la compra personal de un departamento.

## Archivos

- `index.html`: estructura de la aplicación.
- `assets/styles.css`: presentación.
- `assets/app.js`: lógica, cálculos, minuta y editor de zonas.
- `data/app.json`: ficha, comparables, criterios, preguntas y evidencia inicial.

## Guardado

Los cambios se guardan automáticamente en `localStorage` y pueden exportarse/importarse como JSON. La información de uso no se escribe en GitHub.

## GitHub Pages

En el repositorio: **Settings → Pages → Deploy from a branch → `main` / root**.

Luego quedará disponible en `https://bcorrv.github.io/compradepaVF/`.
